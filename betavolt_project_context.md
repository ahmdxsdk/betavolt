# Project Context: BetaVolt - Engineering & Contracting Corporate Website

## 1. Project Overview
- **Client:** Eng. Khaled (via Abu Raghd)
- **Company Name:** BetaVolt (or similar pending domain availability)
- **Industry:** Electromechanical Contracting, Low Current Systems, Data Centers, and Infrastructure.
- **Core Objective:** Build a professional, accessible, and editable corporate website (Web Profile & Portfolio) to showcase services and projects.

## 2. Technical Stack & Architecture
- **Frontend:** React.js / Next.js (for SEO & performance).
- **Styling:** TailwindCSS (for pixel-perfect, responsive UI).
- **Backend/Database:** Supabase (PostgreSQL) for handling dynamic content (Projects, Services, Admin Auth).
- **Auth/CMS:** Supabase Auth + custom admin dashboard for content management.

## 3. Core Features & Requirements
- **Professional UI/UX:** Clean, engineering-focused design. Must be pixel-perfect with distinct layout spacing.
- **Accessibility:** High contrast, clear typography, standard accessibility practices.
- **Dynamic CMS (Editable):** The client must be able to add/edit/delete projects and services without writing code.
- **Portfolio Section:** Filterable projects gallery based on categories.
- **Contact & Location:** Integrated Google Maps, standard contact form.
- **Infrastructure:** Custom `.com` domain and official business emails setup.

## 4. Company Activities & Database Categorization
*The database schema should group the following services into logical categories for the UI/UX menus and database tables:*

**Category 1: Power & Electrical Systems**
- أعمال التركيبات الكهربائية (لوحات توزيع، كابلات، محولات، سويتش جير، إضاءة صناعية، تأريض).
- أعمال الصيانة الكهربائية والتشغيل للمصانع (عقود صيانة دورية، فحص وقائي، طوارئ 24/7).
- أعمال أنظمة الطاقة الشمسية للمباني التجارية والصناعية (Rooftop Solar).

**Category 2: Low Current & Smart Systems**
